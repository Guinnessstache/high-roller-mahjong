Under the hood

One small Node.js process runs everything that has to be trusted: the wall, the claim rules and the faan scoring. Browsers only ever receive what they're allowed to see. Video and audio skip the server entirely and flow directly between players over WebRTC.

  • Three.js
  • Socket.IO
  • WebRTC
  • Express
  • Web Audio
  • node:test

Get started

Take your seat

You'll need Node.js 18+.

git clone https://github.com/Guinnessstache/high-roller-mahjong.git
cd high-roller-mahjong
npm install
npm start

Open http://localhost:3000, pick a name and click Play vs bots, or Create table and share the code.

Browsers only allow the camera and mic on HTTPS pages, so give friends an HTTPS link with a free tunnel:

# Windows: winget install --id Cloudflare.cloudflared
# macOS:   brew install cloudflared
cloudflared tunnel --url http://localhost:3000

Open the https://….trycloudflare.com link it prints, create a table, and hit Copy invite.

It's a single Node process with no database, so any host with WebSocket support works. The repo ships with a Render blueprint and a Dockerfile.

Deploy to Render 
docker build -t high-roller-mahjong .
docker run -p 3000:3000 high-roller-mahjong

Friends on strict mobile or office networks may need a TURN relay for video — set TURN_URL, TURN_USERNAME and TURN_CREDENTIAL.

FAQ

Questions at the table

Which mahjong is this?

Hong Kong (Cantonese) rules with faan scoring: 144 tiles including flowers and seasons, a 3-faan minimum by default, and a 10-faan limit. The host can change the minimum, the limit, the game length, and turn flowers or Seven Pairs on or off.

Is this gambling?

No. Points only exist for the length of a game. There's no payment, cash-out, or account system.

I've never played. Can I still join?

Yes. The in-game guide explains the rules and every scoring pattern, ready hints show which discards leave you one tile from winning, and Easy bots are forgiving.

The game runs at 10 fps on a good graphics card.

Your browser is probably drawing 3D without the GPU. Turn on "Use graphics acceleration when available" in Chrome or Edge settings and restart the browser. The ⚙ menu in-game shows your fps and which GPU is being used.

A friend can't see or hear anyone.

Video is peer-to-peer. Most home networks connect fine with the built-in STUN servers; some mobile carriers and corporate networks need a TURN relay.

Does it work on phones?

Yes — the rack, claim buttons and camera adapt to small screens.
